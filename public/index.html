Localhost vs production

Working on your laptop is not the same as being live.

AreaOn localhostIn production
Addresslocalhost:3000, visible only on your computerA public domain anyone can open
DatabaseA local database with test dataA production database with access control
ConfigurationA .env file on your laptopSecrets configured securely on the server
TestingYou test in your own browserTested on the live domain, as real users reach it
Starting the appStarted by hand; stops when the terminal closesA process manager keeps it running and restarts it
SecurityPlain HTTPHTTPS with an SSL certificate

An application that only runs on localhost can't be used by anyone else. Deployment knowledge is what lets a developer hand over a working product, and explain how it runs.
