# Logo sources

Every logo on the slider is stored locally in `public/assets/logos/<category>/` and listed, in display order, in `public/data/logos.json`. This file records where each one came from. Every source URL below was downloaded successfully (HTTP 200) when the assets were built, and every local file was checked in a browser.

**Trademarks.** All names and logos are trademarks of their respective owners. They are shown for illustration only and do not indicate a partnership, employment, sponsorship or endorsement. Licences below describe the *image file*, not the trademark.

**Sources.** Simple Icons 13.21.0 (CC0, recoloured to brand colours) - https://github.com/simple-icons/simple-icons. Devicon 2.16.0 (MIT) - https://github.com/devicons/devicon. Wikimedia Commons (each file page states its licence). Lucide 0.468.0 (ISC) for generic concept icons, which are not brand logos.

**Attribution required:** `Tally` uses a file licensed CC BY-SA 4.0 (https://commons.wikimedia.org/wiki/File:Tally_-_Logo.png). It was resized to 240 px wide.

## Not sourced

These were requested but not added, because no clean, current, transparent version of the correct brand mark could be verified from a licensable source:

- LIC, Piramal, Hindustan Unilever, IIT Gandhinagar, ICICI Lombard, Johnson Controls (current logo), UltraTech Cement: no suitable file found (Johnson Controls only had an outdated logo, UltraTech only a JPG with a white background, ICICI only ICICI *Bank*, Unilever only the parent brand).
- Microsoft Office: only the outdated 2013-2019 logo was available.
- Plain "Linux" appears once (it was listed under both Cloud and Infrastructure). Windows, Word, Excel, PowerPoint, HTML, CSS, JavaScript and Google Workspace appear once, although they were also listed under the computer education list.
- "WhatsApp Business" uses the standard WhatsApp mark, and "ChatGPT" uses the OpenAI mark, because those are the marks available from the sources.
- Virtual Machines, Cloud Storage, Active Directory, Hyper-V, Networking, REST API, Generative AI, Prompt Engineering, Computer Fundamentals and Internet and Email are concepts, not brands. They use generic Lucide icons and are labelled as such.

To add a logo later: save the file in the right folder under `public/assets/logos/`, then add an entry to `public/data/logos.json` (see README.txt).
